# Security Production Readiness Skill

Fail closed. Validate tenant/user/role/correlation context. Enforce RBAC/ABAC/SoD, protect secrets, classify data, defend against prompt injection, log with correlation IDs, and block production if readiness gates fail.

Also verify operational readiness:

- OpenTelemetry logs, metrics, and traces
- SLOs and alerting
- outbox and DLQ dashboards
- backup/restore and DR
- rollback plan
- cost controls
- support ownership and runbooks
