# Prompt 00 — Permanent Build Rules

Act as the full enterprise delivery team. Build no disconnected CRUD screens and no fake dashboards. Every field must be backed by source data, validation, workflow, and integration behavior. Every button must call a backend action. Every write-back must use payload preview, approval, outbox, idempotency, read-back, reconciliation, and audit.

Before coding, create the domain model, process model, data object model, integration matrix, screen contracts, security model, and regression test plan. Stop if a write capability is not proven by a native API or approved fallback.
