# Prompt 06 — Connector Registry and Provisioning Console

Build object-aware connector registry and provisioning. Every connector must declare supported objects, actions, modes, auth, endpoints, mappings, retry policy, DLQ policy, health, last sync, and payload preview support.

Include SAP S/4HANA, SAP BTP, SAP Integration Suite, SAP Event Mesh, Oracle Fusion REST, Oracle Integration Cloud, Maximo, ServiceNow, AVEVA PI, OPC UA, ESRI, Primavera P6, ADP/UKG/WFS, Ariba/Fieldglass, OpenText, and generic REST/SFTP fallback.
