# Prompt 09 — Workflow, Approval, SoD, and Audit

Build workflow state machines and approval controls for every transaction type. Include four-eyes, threshold approval, risk-based approval, finance/safety/procurement/operations approval, delegation, escalation, e-signature, correction, rejection, cancellation, reversal, and audit timeline.

Rules: author cannot final approve own transaction when four-eyes applies; posted transactions cannot be edited directly; overrides require reason and audit.
