# Prompt 13 - Cross-Cutting Security and Production Readiness

Use this prompt as a cross-cutting gate from Stage 08 onward and as a direct input to Stage 19.

Implement or validate tenant isolation, RBAC/ABAC, RLS, secrets management, data classification, policy checks, prompt-injection defense, rate limits, caching controls, OpenTelemetry, structured logs, audit, backup/restore, DR, SLOs, SLA reporting, release gates, cost controls, and incident runbooks.

No production deployment if identity, tenant context, rate limits, logging, audit, rollback, and recovery are not working.
