# Prompt 08 — Canonical Transaction Model and Posting Path Engine

Create the canonical transaction model and posting path decision engine. The engine decides the correct target object/action/API based on source object, target system, approval status, business rules, connector capability, and fallback policy.

Implement draft, validate, submit, approve, reject, request correction, payload preview, release, queue outbox, post, acknowledge, read-back, reconcile, cancel, reverse, close.
