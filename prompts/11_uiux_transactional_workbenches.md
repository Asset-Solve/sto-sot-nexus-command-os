# Prompt 11 — Enterprise UI/UX as Guided Transactional Workbenches

Build screens only after screen contracts exist. Required screens include command center, work inbox, create/request wizard, transaction detail workbench, approval workbench, posting monitor, reconciliation workbench, connector provisioning console, rules/configuration console, analytics workspace, exception/correction/reversal workbench, AI copilot, audit/evidence center.

Each screen must show current status, next action, owner, approver, blocking reasons, payload preview, audit timeline, source data, connector mode, freshness, and reconciliation state.
