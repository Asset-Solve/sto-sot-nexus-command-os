# Prompt 18 - AI Backbone Governance

Implement or validate the AI backbone only after domain, data, integration, workflow, and security decisions are approved.

Required components:

- model gateway
- model router
- agent orchestrator
- prompt registry
- skill registry
- tool registry
- RAG/retrieval layer
- source trust and citation policy
- policy engine
- eval harness
- human approval queue
- AI audit ledger

Rules:

- Route models by task, data class, tenant policy, cost, latency, and tool capability.
- Record model, prompt version, sources, tool calls, user, timestamp, approval status, and output hash.
- Block autonomous approval, posting, replay, reversal, payroll, finance, safety, permit, procurement, and ERP master-data mutation.
- Add evals for hallucination, citation quality, controlled-action refusal, prompt injection, and regression.
